# 置顶 / Zhiding

macOS 菜单栏工具：把截图、图片和窗口画面「钉」在屏幕上随时对照查看。原生 Swift 实现，画面只驻留内存，不联网、无账号、无埋点。

**当前状态：本机开发原型。尚未完成权限、锁屏与全屏等系统级验收，也没有 Developer ID 签名与公证，请勿作为正式版本分发使用。**

## 功能与状态

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 区域截图并置顶 | 可用（开发验证） | 冻结屏幕画面框选区域生成独立贴图；截图不自动写盘、不自动写剪贴板 |
| 剪贴板 / 本地图片贴图 | 可用（开发验证） | 本地导入 PNG / JPEG；剪贴板支持 PNG / TIFF，只读用户操作时的快照 |
| 多张贴图管理 | 可用（开发验证） | 上限 20 张；独立移动、等比缩放、透明度、鼠标穿透、隐藏/显示 |
| 窗口实时镜像（实验） | 实验受限 | 仅 Debug 构建且首次需确认用途；仅供查看，不能在镜像内操作源窗口；Release 入口禁用 |
| 原窗口可操作置顶 | 未实现 | 旧 AXSubrole 实验路线已证伪并撤下，仅保留不可用说明，不再引导无效授权 |
| 全局快捷键 | 可用（开发验证） | 默认 `⌥⌘1` 截图、`⌥⌘2` 镜像、`⌥⌘3` 剪贴板贴图、`⌥⌘0` 全部隐藏/显示；可修改、可禁用 |
| 隐私保护 | 可用（开发验证） | 睡眠、屏幕休眠、会话切出时隐藏内容、清除镜像帧并停止捕获；恢复显示与重新捕获是两个独立动作 |

## 为什么没有「原窗口置顶」

macOS 没有让第三方应用把**其他应用的窗口**设为永久置顶、且保持可点击输入的公开接口。旧实验曾误把辅助功能的 `AXSubrole` 当成层级开关；Apple SDK 将其定义为只读类型描述，该实现已撤下。相关分析见 [设计总览](./00-设计总览.md) 第 6 节。

窗口镜像可以「置顶查看」，但它是本应用自己的悬浮窗，只能看、不能操作源窗口，不能当作原窗口置顶的等价替代。

## 已知限制

- **锁屏保护未完成验收**：公开的睡眠/会话通知不能覆盖所有锁屏路径，G03 门槛未通过。离开电脑前请主动停止镜像、关闭内容。
- 全屏应用、Stage Manager、Mission Control、多显示器混合缩放的悬浮表现仍待实机验收。
- 镜像采用「停止后重选」的保守换源流程，不支持同一捕获流内无缝换源。
- 发布形态：目前只有本机 ad hoc 签名；无 Developer ID、无公证票据，其他用户机器上的 Gatekeeper 放行不做保证。
- 贴图与镜像内容不会自动保存；关闭即丢弃，退出不提供恢复。

## 构建与运行

要求：macOS 14+，以及 Apple Command Line Tools 或 Xcode（提供 Swift 与 macOS SDK）。无第三方依赖，未创建 `.xcodeproj`，可直接用 Swift Package 开发。

```sh
# 逻辑检查（坐标、图像、资源预算、竞态与能力边界；不需要完整 Xcode）
swift run ZhidingChecks

# 生成开发应用（默认本机架构；--universal 同时构建 arm64 与 x86_64）
swift Tools/BuildApp.swift --universal

# 打开应用：菜单栏图钉图标进入，首次显示管理界面
open build/Debug/Zhiding.app

# 合成内容冒烟检查：不读屏幕/剪贴板、不申请权限，跑完自动退出
swift run Zhiding --smoke-test

# Release 编译（镜像入口禁用，仅保留原窗口置顶的不可用说明）
swift build --configuration release --product Zhiding

# 输出独立验证包到 build/Validation/Debug（不覆盖正在运行的 build/Debug）
swift Tools/BuildApp.swift --validation
```

构建产物在 `build/` 与 `.build/`，均不纳入版本控制。开发包使用 App Sandbox、Hardened Runtime 与本机 ad hoc 签名，仅用于本机验证，不执行上传、公证或安装。

## 测试与验证记录

- 逻辑检查：45 项通过（`swift run ZhidingChecks`，最近一次复跑）。
- 合成冒烟检查：25 项通过（`swift run Zhiding --smoke-test`，最近一次复跑），覆盖多贴图、穿透、隐藏/恢复、100 次创建关闭、Metal 合成帧、隐私交互与能力边界；该检查不访问用户屏幕、剪贴板或文件。
- 以上均为逻辑与合成检查，**不等于**真实 TCC 授权、系统窗口选择器、锁屏、全屏与性能验收。完整验收矩阵见 [开发路线与验收标准](./03-开发路线与验收标准.md) 第 3、5、7 节。

## 隐私与权限

- 不联网、无账号、无埋点，不上传画面或剪贴板内容。
- 区域截图按需申请「屏幕录制」权限；窗口镜像走系统选择器的会话授权；不申请辅助功能、输入监控、摄像头、麦克风或完全磁盘访问权限。
- 截图与镜像内容只驻留内存，只有用户主动复制或保存时才写入剪贴板/文件；日志只记录脱敏错误与性能信息。
- 应用不建立历史库、不含磁盘缩略图，也不读取用户文件，除非用户显式选择导入。
